# Clean-room rules

This project must stay safe for anyone to use and contribute to.

**Allowed sources**
- Our own legally owned retail copy of the game: its data files and executable.
- Mercenaries Recompiled and xboxrecomp (MIT), with their notices kept.
- Public documentation and open-source tools for Pandemic's other games (Star Wars Battlefront), respecting each license.
- Findings shared by other modders with their permission. Credit them.

**Not allowed**
- The leaked Mercenaries source code, or anything derived from it. Don't read it, quote it or "check against" it.
- Any part of the port that its own notes describe as "source-informed" and not since re-derived from the retail game. Use the re-derived versions or derive it ourselves.

**Never committed**
- Game data, extracted assets, disc images, generated recomp C code or memory dumps. `.gitignore` blocks the usual paths; check before every commit.

**Recording evidence**
When you document a format or function, say how it was established: from retail data, from retail code (give addresses), from a live test, or inferred.
